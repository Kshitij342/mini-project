# StudyFlow — Student Assignment Management System

StudyFlow is a web-based application for managing student assignments, tracking deadlines, and monitoring completion progress.

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML, CSS, JavaScript
- Maven

## Features
- Dashboard with assignment statistics
- Create, view, update, and delete assignments
- Search and filter assignments
- Card and list views
- CSV export
- Calendar and upcoming deadlines
- Weekly completion analytics
- Light and dark themes

## Run Locally

1. Install Java 21 and MySQL.
2. Create a MySQL database named `assignment_manager`.
3. Configure the `DB_URL`, `DB_USERNAME`, and `DB_PASSWORD` environment variables.
4. Run:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

5. Open http://localhost:8080
